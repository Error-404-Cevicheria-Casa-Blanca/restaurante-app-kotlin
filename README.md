# restaurante-app-kotlin

App del mesero de la Cevichería "La Casa Blanca" — toma de pedidos desde tablet Android.

## Stack

- Kotlin
- Android SDK 34
- Jetpack Compose + Material 3
- Retrofit 2 + Gson
- Coroutines
- Glide
- Gradle KTS
